## 透明 Logo 导出提示词

从参考图提取中心的双书签图形及gitMaster文字为一个透明PNG。严格保持原始图形外观，蓝色和黄色实心完全不透明，无光晕，无阴影，无辉光，无模糊，无灯光，无纹理，无渐变。画布外部alpha必须为0，图形内部alpha必须为255，仅边缘抗锯齿。顶部圆孔必须真实镂空，圆孔内alpha为0，两片间细缝透明。只要标志加下方gitMaster字标，不要标题、不包含底部三个小示例。保留左蓝右黄双书签、V形切口和共同顶部圆孔，以及参考的字标字形。输出为干净平面矢量风格的品牌素材，如同从矢量软件直接导出的PNG。所有蓝色笔画实心清晰，所有黄色色块实心清晰。图形和文字居中，四周10%透明留白。

## 应用图标母版提示词

从参考图中央提取已经确认的蓝黄双书签符号，制作独立应用图标母版。输出正方形满幅不透明暖白背景 #FAF9F5，背景铺满画布至所有边缘和四角，不绘制外部圆角框、不绘制边框、不加投影。中心只有已确认的双书签符号：左前方深海蓝短书签，右后方金黄色长书签，顶部共享圆形镂空孔，原版两片间细暖白色缝隙，每片V形尾部。严格保留参考造型、蓝黄颜色、倾斜方向和长度比例，不重新设计。符号宽度占画布68%，高度约68%，光学居中，四周均匀留白。无文字、无标题、无编号、无小图、无装饰。二维纯净色块，边缘锐利但保留原有圆角，无渐变无纹理无3D。
