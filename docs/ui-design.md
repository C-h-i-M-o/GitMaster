# 界面与交互规范

当前正式 UI 为 Tauri/React，需优化文件阅读、差异、图形、模型生命周期和虚拟化，优先保证基本交互流畅；可评估 Monaco 等成熟组件，不再禁止 Web 阅读器。普通浏览器仅用于开发预览，实际体验以双平台 Tauri Release 为准。原生为后续可选演进，按体验收益决定，不预设必须重写。详见总计划第 12 节。

## 产品气质

精致、安静、清晰。品牌暂用 gitMaster；中文名不在本轮定案。当前使用 gitmaster-ui.html 的浅绿/暖白工作台，深墨文字、描边图标与克制的局部半透明；不植入原稿演示数据。

## 当前信息架构

- 项目入口：本会话打开过的项目、打开项目、下载项目；缺少 Git 时转入环境引导。
- 工作区：项目/分支导航、文件变更、差异详情、保存版本面板。
- 历史：真实多分支 SVG 提交图，每页 50、最多 1,000 条；搜索只匹配已加载提交。
- 设置：Git 路径、外观、动效、应用信息；凭据不使用普通配置文件保存。

## 新手交互

- 主文案使用“保存版本”“上传版本”等任务语言，补充 Git 术语帮助学习。
- 先让用户理解本机与远端的区别，再提供协作动作。
- 不把 fetch、pull、push 合成不可解释的一键操作。
- 丢弃内容、恢复文件、撤销提交分别展示作用范围和后果。
- 冲突时展示冲突文件与可执行下一步，不承诺自动解决所有冲突。
- 二进制文件只显示可用信息，不伪造文本差异或语义合并。

## 材质与动效

- 玻璃效果仅用于导航、工具条或浮动控件；阅读区域保持高对比背景。
- M0 使用 CSS 透明度/模糊，不声称是真正 Apple Liquid Glass，不读取桌面图像制造折射。
- 动效优先 transform/opacity；交互反馈建议 120–180ms，面板过渡 180–260ms。
- Motion 用于必要的入场/布局转换；不同时引入另一套动画框架。
- 不给每一行文件添加昂贵的背景模糊；长列表先虚拟化再考虑入场动画。
- 支持 `prefers-reduced-motion`；提供清晰键盘焦点、语义标题和状态反馈。
- 当前最低窗口尺寸为 860×620 CSS 像素；浏览器窄屏仍应可读，不据此声称支持移动端。
- 动效目标为参考机器上接近 60fps，必须实测；不把库宣传指标作为项目验收结果。

## 平台演进

Windows/macOS 的 WebView 分别验证。未来 SwiftUI 使用系统材质时保留整体颜色和层次，不逐像素照搬 CSS；旧系统有清晰回退。当前使用原生窗口边框，正式自定义标题栏需另行验证拖拽、缩放和辅助功能。

## M1 历史交互基线

环境面板展示真实版本、规范路径和来源，支持重新检测、选择 Git、恢复自动检测及固定官网入口。仓库区域展示根目录、HEAD/操作状态和四组文件，按需读取单栏差异。列表初始显示每组最多 200 条，继续加载每次追加 200 条；差异文本区域支持键盘焦点和滚动。

加载中禁用互相冲突的操作；刷新失败保留旧快照并标记过期；差异失败保留所选文件并明确提示刷新重试。文本使用 React 文本节点，二进制、冲突、子模块、编码不支持和截断均有中文说明。没有提交/推送/解决冲突按钮。

## M2/M3 已实现交互

- 顶部工具栏、项目菜单、会话项目列表、可折叠分支、SVG 画布、右侧抽屉、常规/外观设置和可展开操作记录已接入真实控制器；旧 M1 环境与差异组件继续复用。
- 节点与全部父边来自 Git，标签不推断分支归属。支持平移、缩放、居中、拖动回弹、方向键/Enter 选择和视口裁剪；未加载父显示边界。弹性与标签显示仅改变 UI，保存失败保留草稿及旧值。
- 本地修改页分开勾选与查看差异，支持整文件暂存/取消暂存。保存版本必须确认整个索引、身份和原样说明；取消/失败保留说明，仅核实本次提交成功后清空。
- 下载、获取、上传和整合各有独立表单与后端确认。上传准备会查询真实远端，表单先说明目标和系统认证组件；最终预览列出源/目标 OID 与全部待上传提交。操作记录只展示脱敏阶段和可靠计数，不提供任意终端或伪进度。
- 冲突页展示三方 OID、编码、换行和结果草稿。采用一侧仅修改草稿，保存并暂存和完成双亲提交分别确认。三栏同步滚动的展示空白不进入保存内容；离开未保存草稿需明确丢弃。
- 统一 dialog 支持 Escape 取消预览、关闭恢复焦点；活动任务/未保存冲突阻止不兼容的切换。浏览器预览禁用 Git，测试替身仅位于忽略的 tests/，生产入口无模拟成功。

实际验证：浏览器默认及 860×620 视口、等效放大布局、键盘、焦点、减少动效、表单恢复和冲突同步滚动已有记录。真实 macOS/Windows 交互、系统 200% 缩放和原生拖拽尚未验收，详见 verification；不声称 60fps。
