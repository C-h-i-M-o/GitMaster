# gitMaster 文档索引

本项目面向 Git 初学者，品牌为 gitMaster。当前正式版主线为 Tauri/React 与独立 Rust 核心，先完成性能、1GB 缓存、功能与双平台交付。达标可长期保留 Tauri；原生仅是正式版后续可选更新。实际证据及已知失败见验证记录。

当前分支切换修复、诊断与性能测量见 [专项 Spec + Plan](branch-switch-fix-spec-plan.md)，实际通过及跳过项以 [验证记录](verification.md) 最新章节为准。

## 文档维护

终端、编辑与设置已实现；本轮即时设置、真实文件系统目录、自动暂存提交和保存方式以总计划第 15 节为准，覆盖补充计划中旧的“应用设置”、忽略开关等设计。第 16 节区分功能收尾、未测专项与后续开发；历史过程记录保留当时语境。

- 先变更需求和接口，再实施代码；新方向的 spec 与 plan 合并维护于 `spec-plan.md` 第 12 节，其他文档引用该节，不重复维护两套计划。
- 区分“已实现”“规划”“未验证”，不得把规划功能描述为现有能力。
- M1 为历史只读基线；M2/M3 写入必须经过确认计划，认证复用受信任的系统组件。Tauri 尚待完成发布验收，原生为未实施可选项；不开发 Git 自动安装器或凭据存储。
- 按用户本轮确认，保留现有项目骨架，代码、`docs/`、`AGENTS.md` 与 README 一同纳入版本管理。后续功能开发仍需单独授权。
