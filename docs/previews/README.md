# 加载动画预览

打开同目录的 `loading-motion.html` 即可离线查看，无需安装工具、联网或打开真实仓库。使用已有开发服务时，也可访问 `/docs/previews/loading-motion.html`。

方案名称为“分支汇流”，第二版已获用户审核通过并接入 gitMaster。此文件保留为离线视觉对照；真实业务使用共享 OperationFeedback 组件。

- 三个场景：打开项目、读取历史、创建提交。
- “演示状态”可切换进行中、较长等待、成功和失败；进行中超过 12 秒自动增加等待说明，不会自动成功。
- 暂停仅暂停图形运动，计时仍继续；“减少动效”或系统同名偏好会关闭运动。
- 读取失败可演示重试；提交失败先演示核对本地状态，不模拟重复写入。
- 打开项目选择“操作成功”后直接展示历史，不展示成功中间页。失败卡片使用目录与断开分支插画；局部提示的动画与文字分别占列，普通窗口间距 28px，极窄窗口间距 20px。
- 页面全部使用示意数据，不读取用户文件、不执行 Git、不保存设置。

设计重点：三色与现有界面的协调、光点汇流节奏、居中与局部两种尺寸、较长等待和异常时的提示。真实业务接入与 Windows 验证记录见 `../verification.md` 最新章节。
