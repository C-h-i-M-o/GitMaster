## 首版 Release 文案草稿

版本暂沿用源码中的 `0.1.0`，正式冻结前核对；本稿不是发布记录。

> GitMaster 帮助你查看项目历史、管理分支、对比和提交文件修改，并与远端仓库协作。文件编辑和内置终端让常用操作集中在同一个工作台。
>
> 请先安装系统 Git，再下载与你的系统和处理器架构匹配的安装包。Windows 安装器负责部署缺失的 WebView2；macOS 使用 DMG 安装。最终说明需填写各平台实测系统要求、签名状态与首次启动步骤。
>
> 可预览并恢复指定文件，或在二次确认后清理选中的未跟踪文件。清理的未跟踪文件无法由 Git 恢复。撤销提交仍待最新候选包完整验收后加入发布功能清单。
